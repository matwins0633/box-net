# 直方体の展開図

直方体の展開図が組み立てられ、また開いていく様子を3Dで見せる、算数の展開図学習用の教材ツールです。
できあがった動きは MP4 動画として保存できます。

## 使い方

Microsoft Edge（または Google Chrome）でページを開くだけで使えます。インストールは必要ありません。

1. 「天面のつけかた」で、天面（ふた）をつける場所を4つのパターンから選びます。
2. 「速さ」で「ゆっくり」「ふつう」「はやい」を選びます。
3. 「▶ 再生」を押すと動きが始まります。スライダーを動かすと、好きな場面を見られます。
4. 「動画をつくる」を押すと動画づくりが始まり、できあがると動画が表示されます。
   「ダウンロード」を押すと保存できます（ファイル名は `box-net-pattern1.mp4` のようになります）。

動画は MP4（H.264）、1920×1080、30fps です。

## 動きの流れ

1. 真上から展開図（5面）を見せる
2. 左の側面と手前の面が立ち上がる
3. 奥の面と右の側面が立ち上がる（カメラは斜め上へ移動）
4. 色が消えて見取り図の表示になる（見える辺は実線、見えない辺は破線）
5. 天面が閉じた位置に現れる
6. 天面 → 奥の面と右の側面 → 左の側面と手前の面 の順に開き、真上から6面の展開図を見せる

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体 |
| `src/net.js` | 展開図の定義と、面の親子構造（ヒンジで回転） |
| `src/timeline.js` | 動きの流れ |
| `src/scene.js` | 3D の描画（床、面、辺、見えない辺の破線、カメラ） |
| `src/video.js` | 動画（MP4）の書き出し |
| `src/main.js` | 画面の操作 |
| `src/style.css` | 画面の見た目 |
| `tests/` | 確認用のテストとスクリプト（ページの動作には不要） |

ライブラリ（[Three.js](https://threejs.org/)、[Mediabunny](https://mediabunny.dev/)）は CDN からバージョンを固定して読み込みます。

## 確認用のテスト

Node.js が必要です。

```sh
npm install
npm test                          # 折りたたんだ面が直方体の面と一致するかのテスト
node tests/framing.mjs            # 流れ全体で面が画面からはみ出さないかの確認
node tests/screenshots.mjs out    # スクリーンショットの撮影
BROWSER_PATH=<Edge の実行ファイル> node tests/video.mjs out 1 fast   # 動画づくりの確認
```
